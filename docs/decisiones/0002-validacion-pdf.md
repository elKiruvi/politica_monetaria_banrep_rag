# ADR 0002 — Validación de PDF con licencia permisiva

**Decisión:** validar firma, apertura y cantidad de páginas con `pypdf` antes de incorporar un archivo descargado. `pypdf 6.20.1` declara licencia BSD-3-Clause en los metadatos del paquete, compatible con el código MIT de este repositorio.

**Evidencia:** los enlaces del histórico son DOI que redirigen al repositorio Banrep; a veces la respuesta final puede ser HTML de un control de acceso. Comprobar extensión o cabeceras por sí solo no basta. La documentación oficial de PyMuPDF indica AGPL v3 o licencia comercial; incorporarlo como dependencia obligatoria sin evaluar la distribución impondría obligaciones distintas. Este ADR solo resuelve la validación de descarga, **no** la extracción de tablas de F4.

**Ventajas:** instalación ligera y legalmente clara para esta etapa; las respuestas HTML y PDF truncados no se almacenan. **Riesgos:** `pypdf` estricto puede rechazar PDF reales con defectos menores; sin prueba real no se relajará el validador ni se declarará compatibilidad con los doce informes. La lectura de páginas no sustituye una revisión posterior de contenido y tablas. **Alternativa:** evaluar PyMuPDF en F4 con licencias y casos reales, o `pdfplumber`/`pdfminer.six` con precisión medible.

**Comprobación acotada:** `PdfReader(..., strict=True)` abrió localmente los cinco PDF del repositorio anterior sin copiarlos; sus números de páginas fueron 56, 61, 54, 54 y 51 (orden alfabético). Esto verifica el parser con esas copias, **no** sus derechos de redistribución ni la descarga actual. Una prueba real de `https://doi.org/rh7c` con el descargador nuevo terminó en redirección hacia un host no autorizado; se rechazó y no se persistió el PDF. No hay evidencia de ingesta de doce informes.

**Límite de validación:** abrir la estructura y contar páginas **no** descomprime todos los flujos de contenido; un PDF con un flujo interno dañado puede guardarse en cuarentena. El procesamiento F4 deberá leer y verificar el texto/tablas y marcar degradación **antes** de permitir activación de cualquier índice. Descomprimir todos los flujos en la descarga ampliaría el riesgo de agotamiento de memoria con PDF hostiles. La respuesta HTTP con compresión se valida según el tamaño descomprimido, sin comparar ese tamaño contra `Content-Length` comprimido.

**Límites operativos:** la compresión HTTP gzip se descomprime por bloques con máximo de salida por llamada; otras codificaciones se rechazan. El plazo se comprueba entre lecturas y antes de publicar el archivo, además del timeout de conexión/lectura, pero **no** interrumpe una operación bloqueante dentro del parser PDF; un límite estricto de CPU requerirá aislamiento del parser en F4. Los clientes HTTP de prueba inyectados deben ser locales, sin credenciales ni hooks, y no compartirse/mutarse concurrentemente.

**Reintentos e idempotencia de descarga:** únicamente fallos de red y HTTP 408/429/5xx se reintentan hasta tres veces por defecto (máximo configurable de cinco), con `Retry-After` acotado o espera exponencial con jitter. Cada intento queda sujeto al mismo plazo; PDF inválido, URL insegura y errores permanentes fallan sin reintento. Al repetirse bytes idénticos se conserva el archivo existente sin alterar su fecha de modificación; una corrección con hash diferente crea otro archivo y preserva el anterior. Esto **no** implementa aún catálogo, actualización de ventana ni snapshot de índice.

Un `Retry-After` mayor al tiempo restante aborta sin solicitar el recurso antes de lo indicado. En sistemas sin `O_NOFOLLOW` no se reutiliza el archivo existente: se reemplaza atómicamente por los mismos bytes para no seguir symlinks entre la comprobación y la lectura. En ese caso la ruta es idempotente, pero su fecha de modificación puede cambiar.

Cada solicitud usa un timeout propio con lectura de máximo dos segundos y conexión no mayor al plazo restante, incluso con clientes HTTP inyectados. El plazo se vuelve a comprobar después de cada bloque y después de validar un archivo existente; **no** es un temporizador que pueda interrumpir inmediatamente una operación bloqueante del parser PDF.
